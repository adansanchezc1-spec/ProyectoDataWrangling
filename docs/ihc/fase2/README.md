## Pendiente antes de una entrega académica final

1. Reclutar voluntariamente a tres personas potenciales y realizar las entrevistas y tareas descritas en el protocolo.
2. Completar la hoja de resultados solo con observaciones reales, calcular métricas y reemplazar las conclusiones provisionales.
3. Revalidar las mejoras con el mismo guion y registrar qué se aplicó o quedó pendiente.
4. Publicar el prototipo en un alojamiento con acceso de lectura y verificarlo en una sesión privada antes de compartir una URL pública.
5. Exportar el informe actualizado junto con la galería de capturas a un único PDF después de cerrar los pasos anteriores.

En esta revisión se verificó la apertura local del prototipo y de la galería. El entorno de navegador integrado no dispone de exportación PDF; no se afirma que exista un PDF final ni un enlace público.
