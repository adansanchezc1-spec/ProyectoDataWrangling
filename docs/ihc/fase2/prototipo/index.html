Campos requeridos

El pipeline actual necesita los seis atributos para aceptar el archivo.

  • Ubicación: barrio o localidad; se normaliza a Bogotá
  • Tamaño: mayor que 0 y hasta 50.000 m²
  • Habitaciones y baños: enteros mayores que 0
  • Estrato: entero de 1 a 6
  • Precio: mayor que 0 y hasta 50.000 millones COP
Los nombres de origen admitidos incluyen localidad, área, habitaciones, baños, estrato y precio.
